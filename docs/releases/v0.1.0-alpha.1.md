# v0.1.0-alpha.1（发布草稿，尚未发布）

本轮新增从工具启动的官方 Codex 终端任务，以及独立授权的额度恢复后自动续跑。已有 Desktop / CLI 会话仍仅监测。

## 变更

- 新建任务：选择项目，打开官方终端；自动续跑默认关闭，单独授权后生效。
- 在同一存活会话中处理明确的额度中断，读取真实额度后核对并继续。提交意图先保存，结果不明不重试；自动恢复默认串行。
- 真实双窗口额度卡，支持多额度桶；未知用量、窗口、重置时间不伪造。
- 深色、浅色、跟随系统；主窗口与托盘同步并保存选择。
- 修复单个会话读取错误导致整条连接被断开的情况。
- 修正 logo 箭头和 macOS Dock 图标的透明边距。

## 计划安装包

| 设备 | 格式 |
| --- | --- |
| Mac Apple Silicon | ARM64 `.dmg` |
| Mac Intel | x64 `.dmg` |
| Windows Intel / AMD 64 位 | x64 `.exe`（NSIS） |

计划附三个安装包与 `SHA256SUMS.txt`。Source code ZIP / TAR 是源码，不是安装包。发布工作流须全部通过后才公开。

## 使用边界

- 需要已安装的官方 Codex CLI，当前核查版本为 0.145.0。托管任务使用独立运行目录，通过官方登录流程授权；应用不复制账号凭据。
- 仅在当前存活的托管进程中恢复。应用重启、终端断开、配置变化或审批等待会关闭自动授权；不会自动冷恢复历史会话。
- 关闭主窗口留在托盘；完全退出会停止自动调度。
- 未提供防休眠、Git 分支校验、Webhook、CLI 自动安装和自启动。
- macOS 使用 ad-hoc 签名，未完成 Developer ID 与公证；Windows 没有代码签名。

## 验证与发布门槛

本地模拟、界面交互和编译结果见 [验证记录](../VALIDATION.md)。真实账号只读连接和额度解析已通过；**真实任务执行、真实额度耗尽后恢复、Windows 实机尚未验收**。这些能力不能由模拟测试代替。

当前不打标签、不发布 Release。先完成用户明确授权的隔离任务执行验证，并记录剩余限制，再确认发布说明。
