首个可下载安装的 Alpha 预览版，采用新版深色界面。

**当前仅支持监测，尚不能在额度恢复后自动续跑。** 开关只选择监测任务，不授权执行；不会自动发送“继续”、接管其他客户端或批准操作。

## 下载

| 设备 | 安装包 |
| --- | --- |
| Mac，Apple Silicon（M 系列） | `Codex-AutoResume-v0.1.0-alpha.1-macos-arm64.dmg` |
| Mac，Intel | `Codex-AutoResume-v0.1.0-alpha.1-macos-x64.dmg` |
| Windows，Intel / AMD 64 位 | `Codex-AutoResume-v0.1.0-alpha.1-windows-x64.exe` |

`SHA256SUMS.txt` 提供三个安装包的 SHA-256 校验值。页面自动生成的 Source code ZIP / TAR 是源码，不是安装包。

## 本版内容

- 深色任务卡、两栏详情窗口、本地会话搜索与连接引导。
- 菜单栏 / 系统托盘小窗，查看任务、控制监测、打开完整窗口。
- 通过官方 Codex App Server 读取本地会话和历史；监测选择及暂停状态保存在本机。
- 新加入的任务默认关闭监测；不删除 Codex 原会话。

额度桶和重置时间尚未接入真实调度；安全接管、实际续跑、防休眠、Git 分支检查和推送尚未实现。设计稿中的示例状态不代表本版已具备这些功能。

## 安装与限制

- 需要预先安装官方 Codex CLI，并通过 Codex 的官方流程登录。应用不附带 CLI，不收集 Token；已核查的协议版本为 `codex-cli 0.145.0`。
- macOS：打开 DMG，将应用拖到 Applications。使用 ad-hoc 签名，**没有 Apple Developer ID 签名和公证**；系统可能阻止首次打开。请核对来源，按系统“隐私与安全性”提供的单应用许可处理；无需关闭系统保护。
- Windows：运行 EXE 安装器。**没有代码签名**，系统可能显示未知发布者提示。首次安装缺少 WebView2 时需要联网下载。
- 关闭窗口后仍在后台监测；请通过托盘菜单退出。

## 验证范围

发布流程在 macOS 和 Windows 云端运行前端检查、前端/路径测试、Rust 测试、格式检查、Clippy 和安装包构建。Mac 检查 DMG 完整性及 ad-hoc 签名；Windows 执行隔离的静默安装检查。

这些检查不等于 Windows 实机 GUI 验收、签名／公证或真实额度耗尽与恢复验证。本版本没有执行真实账号任务。
