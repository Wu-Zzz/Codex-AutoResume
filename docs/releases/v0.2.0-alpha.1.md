# v0.2.0-alpha.1 · 原聊天续跑实验版

新增 **Mac 原 Codex 聊天自动续跑实验入口**，两个 Mac 安装包包含所需组件。开启“自动连接 Codex”并重开一次后，以后照常从原图标启动，再为需要的聊天单独开启续跑。

**已在 Mac Apple Silicon 验证正常启动、原聊天连接和开关可用；真实额度耗尽后的自动恢复仍未完成实测。** 本版本是 Alpha，不代表这一完整流程已验收。

## 本次更新

- 原聊天连接：保留原窗口、原聊天和上下文，工具请求、审批与回复仍由 Codex 处理。
- 修复启动握手和协议兼容问题；连接成功、正在检查与无法续跑分别显示。
- 续跑只接受明确的额度中断，核对真实额度后按原失败轮次提交；结果不明不重发。
- 简化中文提示，统一顶部按钮、额度卡、详情与活动记录的布局。

## 安装与使用

| 设备 | 安装包 | 原聊天功能 |
| --- | --- | --- |
| Mac M 系列 | `macos-arm64.dmg` | 实验组件，已验证本机连接 |
| Mac Intel | `macos-x64.dmg` | 实验组件，尚无 Intel 实机验收 |
| Windows x64 | `windows-x64.exe` | 暂不支持，保留新建托管终端任务 |

安装包与 `SHA256SUMS.txt` 均由本次 GitHub Actions 构建生成；Source code ZIP / TAR 不是安装包。Mac 仅有 ad-hoc 签名，未做 Developer ID 签名与公证；Windows 未做代码签名。

Mac 原聊天：**连接状态 → 自动连接 Codex → 开启**，用 ⌘Q 退出 Codex 后重新打开；先在原聊天中开始任务，再到 AutoResume 开启该聊天的续跑开关。需要默认 zsh 环境、位于 `/Applications` 的 **Codex Desktop 构建 `20770`**。其他构建会拒绝启用。

## 已知限制

- 使用基于官方 0.163.0 源码修改的实验执行程序，并非 OpenAI 官方功能；启用期间暂不支持 Codex 语音。
- 连接或开关可用不等于已成功自动续跑。真实额度耗尽、恢复及原聊天完整续跑仍待验证。
- 重启、连接失效、用户新输入或执行配置变化会关闭聊天续跑授权；不会补跑旧的历史中断。
- 正常结束、用户停止、审批等待或需要补充信息时不自动继续。
- 没有防休眠功能；电脑休眠期间无法按时续跑。
- Windows 原聊天续跑暂不支持；Intel Mac / Windows 实机交互尚未验收。

源码侧已通过 190 项 Rust 单元测试、6 项模拟传输测试、15 项前端测试及静态检查。发布流水线另行构建并测试两种 Mac 架构的实验后端，检查三个安装包后才公开。详细范围见[验证记录](https://github.com/Wu-Zzz/Codex-AutoResume/blob/v0.2.0-alpha.1/docs/VALIDATION.md)。
